    From the document

    An early idea.
    A useful lesson.

    Read RFC 4 ↗Official metadata ↗Errata ↗

    RFC 4 is a checkout timetable for an early network: install equipment, connect a host computer to an IMP (a network switching computer), debug that interface, then test messages with more sites.

    This archive tool retains the seven dated targets in items 2–8 and lets you shift them together. It makes the gaps visible without assuming that the dates were achieved, that work was sequential, or that the same durations suit a project today.

    Model & limitations. Original dates are interpreted as month/day/year in 1969. Offsets are 0, 31, 45, 61, 75, 106 and 136 calendar days. No dependencies, working-day adjustments or completion claims are inferred. Items 9–14 (terminal access, file movement and debugging) have no dates and are not assigned invented ones. The calendar file is a modern export convenience.

    Source evidence, status and archive limitations

    RFC 4, dated items 2–8 (August 1 through December 15, 1969); items 2e and 4b (coordination); items 9–14 (undated follow-on work).

    Official status: UNKNOWN · Legacy stream. UNKNOWN is not the formal HISTORIC classification. These educational adaptations are not current Internet standards.

    No formal successor or updating RFC is listed in the retrieved official metadata. The archived text header says Informational; we retain UNKNOWN from the official catalog.

    The retrieved official errata search showed no matching records. That does not resolve gaps or typographical errors in the source.

    Item 2f refers to an absent item 16; it is not treated as a reference to RFC 16. Item 14b repeats the label 14b3. All six text pages, including three ASCII network configurations, were reviewed. No missing protocol detail is filled in.

    Try it with someone

    A two-minute experiment

    Select the original dates and find the gap between installation of the communication gear and the host–IMP interface target. Then set the first milestone to February 1, 2028. Do leap days change the number of elapsed days?

    Expected observation

    The first gap stays 31 days. Starting on 2028-02-01 places the next milestone on 2028-03-03 and the last on 2028-06-16; the final offset stays 136 days.
