## Longer community post

How can an early network document help people today? Rollout Planner turns an idea from
RFC 4, “Network timetable,” into a small tool for students, small project teams and organizers learning staged rollout planning.
Inspect seven original planned milestone dates alongside a user-chosen first milestone date, retain their calendar-day offsets, and download a CSV or all-day calendar for an original project exercise. Inputs stay in the browser; you can download the result
and continue using the loaded page offline.

Original dates are interpreted as month/day/year in 1969. Offsets are 0, 31, 45, 61, 75, 106 and 136 calendar days. No dependencies, working-day adjustments or completion claims are inferred. Items 9–14 (terminal access, file movement and debugging) have no dates and are not assigned invented ones. The calendar file is a modern export convenience. The official RFC status is UNKNOWN / Legacy, not HISTORIC;
this is not a current Internet standard. No formal successor or updating RFC is listed in the retrieved official metadata. The archived text header says Informational; we retain UNKNOWN from the official catalog.

## Small teaching exercise

Select the original dates and find the gap between installation of the communication gear and the host–IMP interface target. Then set the first milestone to February 1, 2028. Do leap days change the number of elapsed days?

Expected observation: The first gap stays 31 days. Starting on 2028-02-01 places the next milestone on 2028-03-03 and the last on 2028-06-16; the final offset stays 136 days.
